# Bedrock Chat (BrChat) アプリケーション概要

## 1. アプリケーション概要

Bedrock Chat（BrChat）は、Amazon Bedrockを活用した多言語対応の生成AIプラットフォームです。主な機能として以下を提供しています：

- チャット機能
- 知識ベース（RAG）を活用したカスタムボット作成
- ボットストアを通じたボット共有
- エージェントを使用したタスク自動化

## 2. アーキテクチャ

このアプリケーションはAWSのマネージドサービスを基盤としており、インフラ管理が不要です。Amazon Bedrockを利用することで、AWS外部のAPIと通信する必要がなく、スケーラブルで信頼性が高く、安全なアプリケーションを構築できます。

主要コンポーネント：

- **フロントエンド**: CloudFront + S3（React, Tailwind CSS）
- **バックエンド**: API Gateway + Lambda（AWS Lambda Web Adapter, FastAPI）
- **データベース**: DynamoDB（会話履歴）、OpenSearch Serverless（ナレッジベース）
- **認証**: Amazon Cognito
- **AI機能**: Amazon Bedrock、Bedrock Knowledge Bases
- **パイプライン**: EventBridge Pipes、Step Functions（外部知識の埋め込み）
- **セキュリティ**: AWS WAF（IPアドレス制限）
- **分析**: Amazon Athena（S3バケット分析）

## 3. 主要機能

### 3.1 チャット機能
- 基本的なAIチャット機能
- 複数の言語モデルをサポート

### 3.2 カスタムボット作成（RAG）
- 独自の指示とナレッジベースを追加可能
- 既存のAmazon Bedrock Knowledge Basesをインポート可能
- ボットのパーソナライズ

### 3.3 ボットストア
- カスタマイズされたボットをユーザー間で共有
- ボットをスタンドアロンAPIとして公開可能

### 3.4 エージェント機能
- 複雑なタスクを自動的に処理
- 外部ツールからの情報取得
- タスクを複数のステップに分解して処理

### 3.5 管理機能
- API管理
- 必須ボットのマーキング
- ボット使用状況の分析

## 4. デプロイ方法

アプリケーションは以下の方法でデプロイ可能です：

1. **簡易デプロイ**: CloudShellを使用した自動デプロイ
2. **CDKによるデプロイ**: より詳細な設定が可能

デプロイ時には以下のようなオプションを設定できます：
- セルフ登録の有効/無効
- Lambda SnapStartの有効/無効
- IPアドレス制限
- サインアップ可能なメールドメイン制限
- Bedrockリージョン指定

## 5. カスタマイズオプション

- 言語設定（自動検出または手動設定）
- 外部IDプロバイダー連携（Google、カスタムOIDC）
- 新規ユーザーの自動グループ参加設定
- RAGレプリカの設定
- ボットストアの設定
- クロスリージョン推論の設定
- カスタムドメイン設定

## 6. プロジェクト構成

このプロジェクトはCDKを使用してインフラをコード化しており、フロントエンドとバックエンドの両方を含む完全なソリューションを提供しています。複数の環境（開発、テスト、本番）を同じコードベースから管理することも可能です。

## 7. セキュリティ考慮事項

- IPアドレス制限によるアクセス制御
- セルフ登録の無効化オプション
- サインアップメールドメイン制限
- 権限管理のためのユーザーグループ（Admin、CreatingBotAllowed、PublishAllowed）
